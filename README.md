# AI-Assisted Programming Workshop

## Section 1 — Command Description

During this workshop, I worked with Linux commands and practiced creating simplified versions of commands using JavaScript. Two of the main commands I worked with were `grep` and `head`.

The `grep` command is used to search for matching text, while the `head` command is used to display the beginning of a file. I practiced understanding how these commands work and how similar features could be created using JavaScript.

These tools can be run from the command line or terminal. The workshop also showed how different command-line functions can be combined to search through information and display specific parts of the results.

## Section 2 — AI-Assisted Programming

I used AI during the workshop to help me understand Linux commands and how they could be recreated using JavaScript. I asked AI questions about what commands like `grep` and `head` do, what kind of inputs they expect, and how I could test my code.

AI was helpful when I needed explanations of commands, ideas for test cases, and help understanding errors. I still had to run the commands myself and check the results to make sure the suggestions actually worked.

One thing I had to think about independently was whether the output from the program was correct. AI could suggest code or tests, but I still needed to test them in the terminal and decide if the results matched what I expected.

AI also did not always know exactly what was happening in my program. Some suggestions needed to be tested or changed before they worked correctly. This showed me that AI can be useful for programming, but I still need to understand, test, and verify the code myself.
